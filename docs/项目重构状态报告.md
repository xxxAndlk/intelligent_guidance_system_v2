## 快速开始

### 1. 启动基础设施
```bash
cd deploy
docker-compose up -d mysql redis qdrant rabbitmq consul
```

### 2. 初始化数据库
```bash
docker-compose exec mysql mysql -uroot -proot123 medical_system < init/init.sql
```

### 3. 生成代码 (服务代码生成后)
```bash
make generate
```

### 4. 运行服务
```bash
# 运行AI服务
make run-ai

# 运行患者服务
make run-patient
```
